# Book Recommendation System

## Project Overview
This project implements a Book Recommendation System using different recommendation techniques to suggest books to users based on popularity, book characteristics, and user preferences.

## Recommendation Approaches
1. **Popularity-Based Filtering** – Recommends books based on popularity and ratings.
2. **Content-Based Filtering** – Suggests books based on their features and similarities.
3. **Collaborative Filtering** – Recommends books using user rating patterns.
4. **Hybrid Recommendation System** – Combines multiple recommendation approaches to improve recommendations.

## Evaluation Metrics
The models are evaluated using the following metrics:

- **RMSE:** Root Mean Squared Error
- **MAE:** Mean Absolute Error
- **Precision@10**
- **Recall@10**
- **F1@10**
- **NDCG@10**

These metrics help compare prediction accuracy and recommendation quality.

## Dataset
The project uses three CSV files:

- `Books.csv`
- `Ratings.csv`
- `Users.csv`

- Python

- Recommendation System Techniques

## How to Run
1. Open the Jupyter Notebook in Google Colab.
2. Upload the three required CSV dataset files.
3. Run all cells in order.
4. View the generated recommendations and evaluation metrics.

## Project Objective
To explore and compare different recommendation system paradigms and understand their strengths, weaknesses, and effectiveness in generating personalized book recommendations.
